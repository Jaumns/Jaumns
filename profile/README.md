# Jaumns // Control Room

Perfil interativo inspirado na base visual do Jaumns e nos componentes animados do NoxyGalaxy.

- Abas: perfil, projetos, code tracker e lab.
- Tracker com dados públicos do GitHub de `Jaumns` e fallback local.
- Player de áudio local, sem backend, para arquivos em `profile/assets/audio`.
- Fundo contínuo com camadas atmosféricas, ruído, scanlines e motion responsivo.

Abra `index.html` para testar localmente. O workflow em `.github/workflows/profile-pages.yml` publica esta pasta no GitHub Pages.
